# FT8 Plus 协议
## The FT8 Plus protocol enables the continuous, loss-tolerant transmission of up to 64 frames—carrying a maximum of 574 bytes of UTF-8 encoded Unicode data—by extending the FT8 frame type (i3=6).
##  FT8 Plus 协议通过扩展 FT8 帧类型（i3=6），实现了最多 64 帧的连续、容忍丢失的传输，最多可承载 574 字节的 UTF-8 编码 Unicode 数据。
